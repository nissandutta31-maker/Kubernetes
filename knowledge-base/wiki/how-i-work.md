# How I Work

> Capture everything raw and fast, distill deliberately into atomic linked notes, and let
> AI agents run the mechanical parts of that pipeline.

## Context
These are the operating principles behind this [[personal-knowledge-base]]. They explain
*why* the schema in [[CLAUDE]] is shaped the way it is — optimized for low-friction capture
and high-quality, reusable distillation.

## Key points
- **Friction kills capture.** Anything interesting goes into `raw/` immediately, unprocessed.
  Judging it later is cheaper than losing it now.
- **Distill on a second pass.** Turning raw → `wiki/` is where I actually think; doing it
  separately from capture keeps both steps honest.
- **Link aggressively.** A note that isn't linked is effectively lost. Every page earns its
  place by connecting to neighbours.
- **Delegate the mechanical work.** [[ai-coding-tools]] handle the repetitive parts of the
  `raw/ → wiki/` pipeline (extracting atoms, wiring links, updating the [[index]]).
- **Close the loop.** Each session gets a `learnings.md` entry so the *process* improves, not
  just the content.
